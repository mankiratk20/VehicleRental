Vehicle Rental Management System

A console-based Vehicle Rental Management System developed using C++ and Object-Oriented Programming principles to manage vehicle rentals efficiently.

🚀 Features

Add and manage vehicle records

Rent and return vehicles

Customer management

Simple and user-friendly interface

🛠️ Technologies Used

C++
OOP Concepts
File Handling

How to Run

Compile the program

g++ main.cpp -o rental

Run the executable

./rental
